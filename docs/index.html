The resource pack studio, in one app.

OpenPax is a desktop app for making Minecraft: Java Edition resource packs. You can manage the pack, draw textures, animate them and build block models in one window. It's written entirely in Rust.

What works today

Everything a pack needs

You don't need a separate image editor, model tool and zip utility. OpenPax opens the pack folder, shows you its assets and gives each file type its own editor.

Packs

Create a pack for a chosen game version, open a folder, or import a .zip. You can edit pack.mcmeta and export a zip that Minecraft loads.

Explorer

Assets are grouped by namespace and type, with search, filters and a thumbnail grid. Renames and moves bring the .mcmeta and layers along, and deleted files can be restored from the trash.

Pixel editor

Pencil, eraser, fill, picker, line, rectangle, ellipse, select and move. It also has brush sizes, X/Y mirroring, layers with opacity, a pixel grid and a tiling preview.

Texture animation

Edit frames, playback order and per-step timing. Onion skin is available, and a live preview plays at game speed.

3D model editor early

Block and item models render in a wgpu viewport using the pack's own textures. You can add cubes and edit their position, rotation, per-face textures and UVs, with full undo.

Text & JSON

Blockstates, language files and other text open in an editor with line numbers. JSON is validated and the editor jumps to the error, and you can format it in one click.

Command palette

Press Ctrl+K to find any command or file by name. Every shortcut can be rebound.

Crash recovery

Unsaved edits are snapshotted every 20 seconds and offered back if OpenPax didn't close normally. Each pack also reopens the tabs you had open.

Clipboard

Copy, cut and paste pixels, including to and from other apps. A paste lands on a new layer, ready to drag into place.

Principles

Your pack stays your pack

OpenPax is built to sit alongside the files Minecraft already reads, not to replace them.

No surprise rewrites

Files you didn't change are never rewritten. JSON fields OpenPax doesn't understand are left as they are.

Plain PNGs

Layers live in a hidden .openpax folder. The PNG the game reads stays a normal flattened image, and .openpax is left out of exported zips.

Headless core

The pack, paint and model crates have no UI, so the editing logic is unit tested without opening a window.

Where it's going

Roadmap

OpenPax is early software. Here's what's planned next.

  1. 3D modelling, continued

    Move, scale and rotate gizmos, a visual UV editor, painting directly on the model, parent model resolution and display-transform previews.

  2. Animation

    A timeline, a display-transform poser and keyframed rigs.

  3. Pack tooling

    Validation, plus editors for blockstates, item definitions, language files, sounds and fonts, and multi-version overlays.

  4. Bedrock Edition

    Support for Bedrock resource packs.

Get OpenPax

Download

Pick your platform below. Unpack the archive anywhere and run openpax; nothing needs installing. Each download also includes openpax-cli, the command-line tool.

  • Windows: SmartScreen may warn about an unrecognised app. Choose More info → Run anyway.
  • macOS: the app isn't notarised yet. Run xattr -d com.apple.quarantine openpax openpax-cli once in the unpacked folder.
  • Linux: needs GTK 3 (libgtk-3-0), which most desktops already have.
  • Checksums and older versions are on the releases page.
Get started

Build from source

You need a recent stable Rust toolchain. On Linux, install the GTK, xkbcommon and Wayland development packages first.

terminal
# clone and run
$ git clone https://github.com/cantmediaus-design/OpenPax
$ cd OpenPax
$ cargo run --release -p openpax-app

# open a pack (and files) straight away
$ cargo run --release -p openpax-app -- path/to/pack

# checks
$ cargo test --workspace
$ cargo clippy --workspace --all-targets -- -D warnings
openpax-corePack model: pack.mcmeta, asset index, texture metadata, zip import/export.
openpax-paintPixel-art engine: bitmaps, layers, tools, blending, effects, undo history, PNG I/O.
openpax-modelBlock/item model JSON, undoable model document, mesh generation, ray picking, optimisation.
openpax-renderwgpu renderer for the 3D viewport: orbit camera, textured quads, overlays.
openpax-appThe openpax desktop app, built on egui and wgpu.
